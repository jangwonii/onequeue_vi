# 우리의 약속

후속 운영 버전은 ../../sites/promise에 있습니다. 이 폴더는 로컬 v1과 기존 사용자 데이터를 보존합니다. 새 버전은 ChatGPT 로그인과 별도 운영 DB를 사용하며 로컬 계정·기록을 자동 전송하지 않습니다.

친구들과 각자의 목표를 공개하고 같은 7일 동안 약속 4회를 지키는 웹 앱입니다. 사용자가 제공한 「할 일은 달라도, 약속은 함께 지키는 7일」 기획의 친구방 첫 버전을 구현했습니다.

기존 루트의 SEVEN, 배포된 SEVEN, 한 칸, 책갈피와 코드·계정·DB를 분리합니다. 기존 SEVEN의 목표별 횟수·수면 사후 인증 규칙은 적용하지 않습니다.

## 실행

Node.js 24 이상이 필요합니다. 실행 패키지 추가 설치는 필요하지 않습니다.

```powershell
cd C:\Users\이장원\Documents\ChatGPT\onequeue_vi\apps\promise
npm start
```

http://127.0.0.1:4190 에서 엽니다. 데이터는 `data/promise.sqlite`에 저장됩니다. Node 내장 SQLite의 experimental 경고가 표시될 수 있습니다.

처음 화면에서 **가상 친구방 체험하기**를 누르면 가상의 네 사람과 예시 기록이 있는 독립된 체험방이 생깁니다. 실제 친구방에는 가상 참가자가 들어가지 않습니다. **하루 뒤 체험**으로 날짜를 넘겨 미달·종료·결과 확정을 살펴볼 수 있습니다. 체험방에서 새 시즌을 준비할 때는 **가상 친구 준비 완료**로 예시 친구들의 동의를 대신합니다. 체험방 날짜는 실제 방이나 서버 시간을 바꾸지 않습니다.

실제 계정 사용 순서:

1. 각자 회원가입합니다. 한 PC에서는 다른 브라우저 프로필이나 시크릿 창을 사용하면 두 계정으로 확인할 수 있습니다.
2. 방장이 친구방과 시작일을 만들고 초대 링크를 복사합니다.
3. 초대받은 친구가 같은 서버에서 로그인 후 참여합니다. 정원은 2~10명입니다.
4. 각자 행동·날짜 4일·마감 시각·완료 조건·선택 이유를 작성합니다.
5. 모두 약속 카드를 확인하고 준비 완료하면 방장이 시작합니다.
6. 오늘의 인증을 제출하고 친구 기록에 반응합니다. 앱은 5초마다 공유 상태를 갱신합니다.
7. 종료 후 검토가 끝나면 약속 이행 순위·완주 여부·회고를 확인하고 다음 시즌을 준비합니다.

## 첫 제품의 범위

- 실제 계정과 초대 전용 친구방, 구성원 접근 검사, 초대 링크 재발급
- 7일·목표 1개·서로 다른 공식 날짜 4일·하루 최대 인증 1회
- 목표·시작일 수정 또는 새 참가자 합류 시 모두의 준비 해제, 시작 후 잠금
- 서버 한국시간 기준 날짜·마감 판정. 브라우저가 보낸 날짜·사용자·분 수를 인증 근거로 사용하지 않음
- 텍스트 자기신고 또는 서버에 저장되는 누적 타이머 + 텍스트 기록
- 친구들의 오늘 상태, 인증 피드, 3종 반응, 앱을 열어 둔 동안의 마감 전 안내
- 인증 후 24시간 동안 확인 요청. 요청 자체로 점수를 차감하지 않고 방장이 잠긴 기준으로 검토. 방장 본인의 인증은 다른 참여자가 검토
- 7일이 끝난 다음 24시간이 지나고 미해결 검토가 없어야 결과 확정
- 1회 25점, 같은 점수는 공동 순위. 순위와 4/4 완주 구분
- 첫 미달 이후 복귀 표시. 과거 실패를 복구하거나 공식 점수를 추가하지 않음
- 회고·다음 시즌·지난 시즌 조회. 새 시즌은 기존 목표를 복사하고 준비 상태 초기화

사진 업로드, 앱이 닫힌 상태의 푸시 알림, 친구 독촉, 별도 채팅, 100인 리그, 결제·상금, AI 판정은 포함하지 않습니다. 타이머는 경과 시간만 확인하며 실제 집중·운동·수면의 사실을 증명하지 않습니다. 기록과 반응은 해당 친구방 참여자에게 공개됩니다.

## 로컬 실행과 배포 구분

이 버전은 로컬에서 구현·검증했으며 인터넷에 배포하지 않았습니다. `127.0.0.1` 초대 링크는 다른 기기의 친구에게 공유해도 이 서버로 연결되지 않습니다.

직접 운영할 때 사용할 수 있는 환경 변수:

| 변수 | 기본값 | 의미 |
| --- | --- | --- |
| `PORT` | `4190` | 서버 포트 |
| `HOST` | `127.0.0.1` | 수신 인터페이스 |
| `DATABASE_PATH` | `./data/promise.sqlite` | 영구 DB 파일 |
| `PUBLIC_ORIGIN` | 비어 있음 | 공개 실행 시 정확한 HTTP(S) origin, 끝에 `/` 제외 |

단일 Node 프로세스와 영구 SQLite 디스크를 전제로 합니다. HTTPS·백업·운영 정책은 별도 배포 작업입니다. 비밀번호는 scrypt+salt, 세션은 해시된 토큰과 HttpOnly/SameSite 쿠키를 사용합니다. 교차 출처 변경 요청을 차단하고 인증·쓰기 횟수를 제한합니다. 비밀번호 찾기, 계정 삭제, 방장 변경·부재 시 분쟁 중재는 아직 없습니다. 실서비스의 보안·확장성 검증을 대신하지 않습니다.

## 검증

```powershell
npm test
npm run build
npm run test:browser
```

브라우저 테스트는 기존 `onequeue-mcp/node_modules/playwright`와 Edge를 사용합니다. `PLAYWRIGHT_MODULE`, `BROWSER_CHANNEL`로 다른 설치 경로를 지정할 수 있습니다. 테스트는 메모리 DB와 임시 DB만 사용합니다.

원큐 MCP 전체 검증:

```powershell
cd ..\..\onequeue-mcp
npm run verify:promise
```

검증 결과는 이 앱의 `.onequeue/verification.json`, 화면은 `test-results/`에 저장합니다. MCP 미리보기는 별도 DB로 실행하고 검증 후 종료합니다.

- 규칙·API 테스트 9개: 권한, 초대, 준비 무효화, 잠금, 중복 동시 요청, 한국시간·마감·휴식일, 타이머, 검토 권한·유예, 공동 순위, 회고·시즌 이월, 재시작 후 저장
- 브라우저: 가상 시즌 전체, 실제 두 계정의 가입·초대·약속·동의·시작·타이머·인증·확인 요청·검토, 이전 시즌, 390/320px 반응형, 사용자 입력 안전 표시
- `npm run build`는 `dist/`에 독립 Node 실행 패키지를 만듭니다. 정적 호스팅만으로는 동작하지 않습니다.
