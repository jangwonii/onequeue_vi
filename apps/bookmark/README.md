# 책갈피 — 나의 작은 서재

원큐 MCP로 실행·검증한 개인용 독서 기록 앱입니다. 다른 앱과 별도 폴더·데이터베이스·포트를 사용합니다.

## 실행

Node.js 24 이상에서 이 디렉터리를 작업 폴더로 실행합니다. 별도 패키지 설치는 필요하지 않습니다.

```powershell
npm start
```

[http://127.0.0.1:4189](http://127.0.0.1:4189)에서 사용할 수 있습니다. 데이터는 `data/bookmark.sqlite`에 저장됩니다. 서버가 실행 중이어야 접속할 수 있습니다.

## 사용 흐름

1. **책 추가하기**에서 제목·저자·전체 페이지·분류·표지 색상을 입력합니다.
2. 책 표지를 눌러 상세 화면을 열고 **지금 읽기 시작** 또는 읽은 페이지를 기록합니다.
3. 마지막 페이지까지 기록하면 완독 상태와 연간 목표에 반영됩니다.
4. 별점과 메모를 저장하면 **독서 노트**에서 다시 꺼내볼 수 있습니다.
5. 제목·저자 검색, 독서 상태 필터, 최근 기록·제목·진행률 정렬을 이용할 수 있습니다.
6. **기록 내려받기**는 전체 책·별점·메모·연간 목표를 JSON으로 저장합니다.

표지는 외부 책 이미지가 아니라 입력한 제목과 색상으로 구성합니다. 도서 검색이나 ISBN 자동 입력, 외부 서점 연결은 없습니다.

처음에는 빈 서재입니다. **가상의 예시 책장 보기**를 누르면 가상 제목과 저자로 만든 4권을 추가합니다. 모든 예시 책에는 별도 표시가 있고, 상세 화면에서 개별 삭제할 수 있습니다. 예시 데이터도 서재 통계에 포함됩니다. 예시 추가는 빈 서재에서만 가능합니다.

## 기록 규칙

- 책은 최대 500권, 제목 120자·저자 80자·메모 4,000자까지 입력할 수 있습니다.
- 전체 페이지는 1~20,000의 정수이며, 읽은 페이지는 0~전체 페이지입니다.
- 새 책은 ‘읽고 싶은’, 읽기를 시작하거나 진행을 기록하면 ‘읽는 중’, 전체 페이지에 도달하면 ‘다 읽은’ 상태입니다.
- 이미 완독한 책에 같은 페이지를 다시 저장해도 완독 횟수가 늘지 않습니다.
- 페이지를 되돌리거나 전체 페이지를 늘려 미완독이 되면 연간 완독 집계에서 빠집니다.
- 연간 목표는 한국 시간의 해당 연도에 완독한 책 수로 계산하며, 목표는 1~200권으로 수정할 수 있습니다.
- 삭제는 책과 메모를 함께 삭제합니다. 앱에서 확인 단계를 거치며 자동 복구 기능은 없습니다.

## 검증

원큐 MCP 프로젝트 ID는 `bookmark`입니다. 원큐 MCP 디렉터리에서 다음 명령을 실행합니다.

```powershell
npm run verify:bookmark
```

실제 stdio MCP 호출로 명세 저장 → 테스트·빌드 → 격리된 미리보기 → 브라우저 조작·조건 확인을 수행합니다. 일반 사용 데이터와 별도 DB를 사용하며 검증용 서버는 종료합니다. 보고서는 `.onequeue/verification.json`, 근거 이미지는 `.onequeue/artifacts/`에 있습니다.

확인한 내용:

- API 통합 테스트 **5개**: 등록·수정·삭제, 잘못된 입력, 진행 상태 전환, 중복 완독 방지, 연도별 집계, 노트·별점·목표, 예시 데이터 표시, 서버 재시작 후 저장 유지, 교차 출처 요청 차단
- 브라우저: 실제 등록·수정·삭제, 진행·완독, 새로고침 후 별점·메모 유지, 검색·필터·정렬, 목표 변경, JSON 내보내기, HTML 입력 이스케이프
- 화면: 데스크톱 및 **390px·320px** 모바일 가로 넘침 확인, 모바일 상세 화면에서 페이지 기록
- 원큐 MCP 완료 조건 **6개**: API·빌드·브라우저 검증, 새로고침 후 책 표시, 진행률 50% 표시, 저장한 노트 표시

직접 실행하려면 `npm test`, `npm run build`, `npm run test:browser`를 사용합니다. 브라우저 테스트는 상위 원큐 MCP에 설치된 Playwright와 Edge를 사용합니다.

## 사용 범위

이 컴퓨터에서 사용하는 로그인 없는 개인용 앱입니다. 서버는 루프백에서만 실행하며 인터넷 공개, 여러 사용자 계정, 기기 간 동기화, 전자책 읽기 기능은 제공하지 않습니다. 실제 독서 여부를 자동 측정하지 않고 사용자가 입력한 진행 상황을 기록합니다.
