# 출고 데스크

OneQueue MCP를 이용한 중간 복잡도 앱 제작·검증용 로컬 파일럿. 한 운영자가 자신의 PC에서 재고 입고, 여러 품목 주문, 예약, 출고, 취소, 검색, 백업과 복구를 처리합니다. 계정과 공개 배포는 이 테스트 범위에 포함하지 않습니다. 실제 주문 데이터 대신 합성 데이터를 사용합니다.

## 계약
- R-stock: SKU 중복 및 음수·소수 수량 거절, 입고 후 현재고/예약/가용 재고 표시.
- R-order: 다중 품목 주문을 원자적으로 예약. 부족하면 어느 품목도 예약하지 않음. 출고는 정확히 한 번 현재고 차감, 취소는 예약 해제, 종료 주문 재처리 거절.
- R-data: SQLite 영속 저장, JSON 다운로드와 검증된 백업 복원, 손상 백업 거절 시 기존 데이터 보존.
- R-ui: 데스크톱/390px 모바일에서 등록·주문·출고·취소·검색·내보내기·복구 가능, 키보드 입력 및 대표 텍스트 대비 확인.
- R-safe: 로컬 호스트 전용, 외부 출처 변경 요청 차단, 입력 텍스트로 렌더링, 제한된 요청 크기.
- R-build: 독립 실행 폴더 생성 및 해당 산출물에서 실제 브라우저 흐름 검증.

## 디자인
카드형 대시보드와 좌우 작업대 두 방향을 비교했습니다. 반복 입력과 주문 상태 비교가 중심이므로 상단 도구 모음 + 재고 표 + 주문 작업대를 선택합니다. 기존 책갈피의 표지 갤러리, 한 칸의 집중 화면과 다른 밀도 높은 운영 화면입니다. 짙은 남색과 아이보리, 초록 상태 강조, 시스템 글꼴, 명시적 레이블과 인라인 피드백. 모바일에서는 한 열로 쌓이며 모든 기능을 유지합니다. 자동 갱신 대신 명시적 새로고침을 사용합니다.

## 운영
Node 24+, 루프백 단일 프로세스/단일 운영자 파일럿. data/dispatch.sqlite 사용. JSON 백업은 전체 상태를 포함하며 복원은 전체 교체이므로 UI 확인을 요구합니다. 복원 전 자동 SQLite 스냅샷을 보관합니다. 앱 종료 후 DB 파일 복사도 가능합니다. 다른 기기 공동 사용, 로그인, 공개 호스팅, 부하 SLA는 제공하지 않습니다.
