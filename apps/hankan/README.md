# 한 칸 — 나의 작은 집중 공간

원큐 MCP를 Codex에 연결한 뒤 만든 로컬 개인용 할 일·집중 타이머 앱입니다.

## 사용

Node.js 24 이상에서 이 폴더를 작업 디렉터리로 실행합니다. 별도 패키지 설치는 없습니다.

```powershell
npm start
```

[http://127.0.0.1:4188](http://127.0.0.1:4188)에서 열립니다. 서버 프로세스가 실행되는 동안 이용할 수 있습니다. 데이터는 `data/hankan.sqlite`에 저장됩니다.

- 할 일 추가·수정·삭제, 중요도 지정, 완료·다시 열기, 진행 상태 필터
- 할 일을 선택하거나 자유 집중으로 15·25·50분 타이머 실행
- 타이머 일시정지·재개·초기화, 새로고침과 서버 재시작 후 상태 복구
- 완료된 집중 세션 기록과 오늘의 집중 시간, 최근 100회 기록 조회
- 할 일과 최근 집중 기록 JSON 내려받기
- 모바일 화면, 키보드 접근, 빈 화면 안내

완료까지 채운 집중 시간만 기록됩니다. 타이머를 초기화하면 중단된 시간은 기록하지 않습니다. 브라우저를 닫았다가 열어도 서버에 저장한 종료 시각으로 완료 여부를 계산합니다. 모든 시간 표시는 한국 시간을 기준으로 합니다. 기본 데이터는 비어 있으며 테스트에 사용한 샘플은 별도 DB에 있습니다.

로그인이 없는 **이 컴퓨터의 개인용 앱**입니다. 서버는 루프백 주소에서만 실행합니다. 인터넷 공개·다중 사용자·계정 동기화는 지원하지 않습니다.

## 원큐 MCP에서 사용

등록된 프로젝트 ID는 `hankan`입니다. 원큐의 `inspect_project`, `run_checks`, `start_preview`, `browser_action`, `browser_assert`로 실행·검증할 수 있습니다.

원큐 MCP 폴더에서:

```powershell
npm run verify:hankan
```

검증은 실제 stdio MCP 클라이언트로 진행하며, 별도 메모리/파일 DB를 사용합니다. 보고서는 이 앱의 `.onequeue/verification.json`에 저장됩니다. 검증용 미리보기는 종료하며, 일반 앱 실행 데이터와 분리합니다.

이 버전에서 확인한 내용:

- API 통합 테스트 4개: 할 일 CRUD·입력 검증, 타이머 시간 계산·중복 완료 방지, 초기화·잘못된 대상 차단, 서버 재시작·교차 출처 요청 차단
- 브라우저 테스트: 실제 입력·수정·삭제, 필터, 새로고침 유지, 타이머 일시정지·재개, 내보내기, HTML 입력 표시, 데스크톱·390px 모바일
- MCP 완료 조건 6개: API 테스트, 빌드, 브라우저 흐름, 새로고침 후 할 일 유지, 일시정지 유지, 완료 상태 표시

집중 세션 완료 시각은 API 테스트에서 주입한 시계로 검증했습니다. 실제 사람이 15분 동안 기다리는 테스트는 수행하지 않았습니다. 브라우저에서는 실제 타이머 시작·일시정지·재개를 확인했습니다.

직접 검증하려면 `npm test`, `npm run build`, `npm run test:browser`를 사용합니다. 브라우저 테스트는 상위 원큐 MCP 패키지에 설치된 Playwright와 Edge를 사용합니다.

## Codex 연결

Codex 사용자 설정에 `onequeue`라는 stdio 서버를 등록했습니다. 설치된 Codex의 `mcpServerStatus/list` API로 도구 10개 인식을 확인했습니다. 원큐 서버를 등록하는 [공식 Codex MCP 설정 안내](https://learn.chatgpt.com/docs/extend/mcp?surface=cli)에 따라 CLI로 등록했으며, 기존 설정은 유지했습니다.

연결 결과는 작업 공간 루트의 `.onequeue/codex-connection.json`에 있습니다. 기존 대화의 도구 목록은 클라이언트의 설정 갱신 시점에 영향을 받습니다. 연결 검증과 별개로 이번 앱의 실행·검증은 명시적으로 생성한 stdio MCP 클라이언트에서 실제 원큐 도구를 호출해 수행했습니다.
