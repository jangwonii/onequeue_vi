# SEVEN — 친구와 함께 지키는 7일

실제 계정, 초대 전용 친구방, 공유되는 인증 기록을 갖춘 Node.js 웹 앱입니다. 가상의 참가자는 생성하지 않습니다.

원큐 바이브코딩의 로컬 MCP 첫 제품은 별도 [`onequeue-mcp/`](onequeue-mcp/README.md)에 있습니다. AI 에이전트에서 프로젝트 조회·실행·테스트·브라우저 검증을 호출할 수 있으며, 검증용 DB는 기존 앱 데이터와 분리됩니다.

## 인터넷에서 사용하기

공개 서비스: **https://seven-routine-club.weun2002.chatgpt.site**

공개 버전은 `sites/seven/`에 있으며 Cloudflare Workers + D1에 배포했습니다. 본인과 친구 모두 **ChatGPT 로그인**을 사용합니다. 처음 로그인하면 표시 이름을 정한 뒤 친구방을 만들고 **친구 초대**의 링크를 공유하세요. 공개 첫 화면은 누구나 열 수 있지만 친구방 기록은 해당 방 참여자에게만 표시됩니다.

공개 버전은 로컬 Node.js 버전과 별도의 데이터베이스를 사용합니다. 로컬 아이디·비밀번호와 데모 기록은 자동 이전되지 않습니다. 로컬 서버를 켜 놓지 않아도 공개 서비스에 접속할 수 있습니다.

배포 성공과 실제 사이트의 화면·DB 상태 확인·비로그인 접근 차단·로그인 이동을 확인했습니다. 두 사용자의 전체 참여 흐름은 로컬 클라우드 실행 환경에서 호스팅 인증 헤더를 모사해 검증했으며 실제 사람 두 명의 ChatGPT 인증을 대신 수행하지는 않았습니다.

## 로컬 Node.js 버전 실행

Node.js **24 이상**이 필요합니다. 앱 실행에 별도 패키지 설치는 필요하지 않습니다. Node 내장 SQLite를 사용하며 현재 실행 환경에서 experimental 경고가 출력됩니다.

```sh
npm run dev
```

이 컴퓨터에서 http://localhost:4173 으로 접속하세요. 기본값은 루프백 주소이므로 외부에 공개되지 않습니다. 데이터는 `data/seven.sqlite`에 저장됩니다. 이전 데모의 브라우저 기록은 실제 계정으로 가져오지 않습니다.

1. 각자 아이디·비밀번호로 계정을 만듭니다.
2. 한 사람이 친구방을 만들고 **친구 초대**에서 링크를 복사합니다.
3. 친구가 같은 서버의 링크로 접속하고 로그인 후 참여합니다.
4. 각자 목표를 제출하고 친구방에서 서로의 목표를 확인합니다.
5. 최소 2명, 모든 구성원의 목표와 상호 확인이 완료되면 방장이 시작합니다.
6. 같은 7일 동안 인증하며 친구 기록·응원·달성률 순위를 공유합니다.

## 다른 기기의 친구와 접속

`localhost`는 링크를 연 기기 자신을 뜻합니다. 인터넷에서 친구를 초대할 때는 위 공개 서비스 주소를 사용하세요. 아래는 로컬 Node.js 버전을 직접 운영할 때의 안내입니다.

신뢰할 수 있는 동일 사설 네트워크에서 확인하려면 PowerShell에서 실행하세요.

```powershell
$env:HOST = '0.0.0.0'
npm start
```

호스트 PC의 사설 IP 주소로 접속한 뒤 초대 링크를 복사하세요. 예: `http://192.168.1.10:4173`. PC가 켜져 있어야 하며 방화벽에서 해당 사설 네트워크 접속이 허용되어야 합니다. 공용 인터넷에 HTTP 포트를 직접 노출하지 말고 HTTPS 역방향 프록시를 사용하세요.

## 서버 배포

`npm run build`는 서버 실행에 필요한 파일을 `dist/`에 구성합니다. **정적 호스팅만으로는 동작하지 않습니다.** `dist/`에서 `npm start`로 실행할 수 있으며 Node 24+와 쓰기 가능한 영구 디스크가 필요합니다.

환경 변수:

| 변수 | 기본값 | 용도 |
| --- | --- | --- |
| `HOST` | `127.0.0.1` | 컨테이너/역방향 프록시 환경에서는 `0.0.0.0` |
| `PORT` | `4173` | HTTP 서버 포트 |
| `DATABASE_PATH` | `./data/seven.sqlite` | 영구 디스크에 저장할 DB 파일 |
| `PUBLIC_ORIGIN` | 비어 있음 | 배포 시 실제 HTTPS 주소, 끝에 `/` 제외 |

`.env.example`을 참고하세요. `.env` 파일을 만들었다면 `node --env-file=.env server.mjs`로 불러올 수 있습니다. npm 명령이 `.env`를 자동 로드하지는 않습니다.

Docker 실행 예시:

```sh
docker build -t seven .
docker run -d --name seven --restart unless-stopped -p 127.0.0.1:4173:4173 -v seven-data:/app/data -e PUBLIC_ORIGIN=https://your-actual-domain.example seven
```

실제 도메인으로 변경하고 HTTPS 역방향 프록시를 연결하세요. `/api/health`로 상태를 확인할 수 있습니다. 컨테이너의 `/app/data`는 반드시 영구 볼륨으로 유지하세요. Docker 파일은 제공했으나 이 작업 환경에는 Docker가 없어 컨테이너 실행 자체는 검증하지 않았습니다.

한 서버 프로세스와 로컬 영구 SQLite 파일을 전제로 합니다. 여러 서버 복제본이나 임시 파일시스템에 그대로 배포하지 마세요. 백업은 서버를 중지한 뒤 데이터 디렉터리 전체를 복사하거나 SQLite의 일관된 백업 방식을 사용하세요.

## 구현 규칙

- 친구방은 최대 100명, 계정당 방 생성은 최대 30개입니다. 자동 공개 매칭은 제공하지 않습니다.
- 초대 링크는 무작위 256비트 코드입니다. 방장만 조회·재발급할 수 있으며, 재발급한 즉시 이전 링크는 무효입니다.
- 링크를 아는 사용자는 시작 전에 참여할 수 있습니다. 시작 후 새 참가자는 받지 않습니다.
- 시작 전에 모든 친구가 다른 구성원들의 목표를 확인합니다. 목표를 수정하면 그 목표의 확인 기록이 취소됩니다. 오래된 목표를 보고 보내는 확인 요청은 거절됩니다.
- 방장이 시작하면 서버 한국 시간으로 모두 같은 7일을 시작하며 목표와 기준이 잠깁니다.
- 공부·운동: 7일 중 3회 이상, 1회 20분 이상. 수면: 5회 이상, 18:00~23:59의 취침 마감 시각.
- 서버가 인증 날짜와 계정 소유권을 결정합니다. 클라이언트가 보내는 임의 날짜·다른 사용자 ID는 사용하지 않습니다.
- 하루 한 번, 예정 횟수까지만 인증 가능합니다. DB 제약과 트랜잭션으로 동시 중복 제출을 막습니다.
- 수면은 다음 날 전날 기록을 제출하며 마지막 날 기록은 8일째까지 제출합니다. 9일째에 최종 결과가 확정됩니다.
- 전체 예정 횟수 대비 달성 비율로 순위를 계산하며 정확한 비율이 같으면 공동 순위·공동 우승입니다.
- 화면은 5초마다 갱신합니다. 입력 중인 대화상자는 유지하며, 제출 시 서버가 최신 상태로 다시 검증합니다.

## 계정과 데이터

비밀번호는 salt를 붙인 scrypt 해시로 저장합니다. 세션은 무작위 토큰과 서버 저장 해시를 사용하며 HttpOnly / SameSite 쿠키로 전달합니다. `PUBLIC_ORIGIN`이 HTTPS이면 Secure 쿠키를 사용합니다. 변경 API는 다른 출처의 요청을 차단하고 JSON만 받습니다. 로그인 및 쓰기 요청 제한, 방 구성원별 접근 검사를 적용했습니다.

이름·목표·인증 기록은 그 방의 구성원에게만 보입니다. 사용자 입력은 HTML 이스케이프합니다. 외부 글꼴은 Google Fonts에서 불러오며 실패하면 기본 글꼴을 사용합니다.

텍스트 자기 기록을 공유하는 방식이며 사진 업로드·증빙 사실 여부 자동 검증은 제공하지 않습니다. 상금 결제·지급, 비밀번호 찾기, 계정 삭제, 참가자 추방은 아직 없습니다. 참가자 추가·배포 정책이 필요한 공개 서비스 운영 전에는 별도 운영 설계가 필요합니다.

## 검증

```sh
npm test
npm run build
```

Playwright와 Chromium/Edge를 사용할 수 있는 환경에서는 다음도 실행할 수 있습니다.

```sh
npm run test:browser
```

`PLAYWRIGHT_MODULE`로 Playwright의 `index.mjs` 경로를 지정할 수 있습니다. 브라우저 테스트는 별도 메모리 DB와 임시 포트를 사용하므로 실제 사용자 데이터를 건드리지 않습니다. 기본 브라우저는 Edge이며 `BROWSER_CHANNEL`로 변경할 수 있습니다.

- 모델 테스트: 최소 기준, 중복·기간 외 인증, 수면 날짜, 비율 기반 동점
- API 통합 테스트: 서로 다른 계정의 초대·권한, 목표 확인, 잠금, 동시 요청, 서버 재시작 후 데이터 유지
- 브라우저 테스트: 두 계정의 실제 화면 흐름, 자동 갱신, 친구 기록, 공동 시작, 모바일 레이아웃

주요 파일: `server.mjs`, `backend/store.mjs`, `model.js`, `app.js`, `styles.css`. 원래 스킬의 `SKILL.md`와 `agents/openai.yaml`은 보존했습니다.
